Features

Built for teams who ship fast

Manual test maintenance breaks the moment your UI drifts. QAmate pairs Playwright-native tooling with an AI that verifies before it ships.

Self-healing locators

Three-tier recovery — primary selector, derived fallbacks, fingerprint scan. Every heal is logged per run so you know exactly what changed.

AI agent

Drives your app in a live browser, authors tests, and re-runs until green. GUIDED and AUTO modes with full session persistence.

Bring your own key

Claude, OpenAI, or an offline mock. Secrets live in your environment and the OS keychain — never committed to git.

Playwright-native

Record, run, trace, video, and network capture with JUnit-authoritative results. Checkpoint flows keep running after a failure.

Projects & context

Per-app URLs, credentials, context folders, and optional private suites. Demo against playwright.dev — no login required.

Open source · MIT

The full desktop IDE, engine, and agent — free to use, fork, and extend. ~218 offline unit tests guard the core.

How it works

From explore to verified green

A layered pipeline — PRD → explore → synthesize → self-heal. Three steps to reliable end-to-end coverage.

Record or describe

Use the built-in recorder for Playwright codegen, or let the agent explore your app with observe() and intent-based actions.

Author with checkpoints

Milestone-based tests with critical, normal, and minor severity. The agent fills gaps, adds assertions, and runs a collect-only gate before delivery.

Verify before ship

Every agent-authored test runs headless twice — only reported passed when both runs are green. Self-heal kicks in when selectors drift.

The IDE

One workspace for the full loop

Test explorer, agent dock, editor, coverage, and results — designed for clarity, not clutter.

  • Flow tree & recorderOrganize suites by module. Record flows, review assertions, export to Jira.
  • Agent dockGUIDED pauses for your approval; AUTO proceeds with auditable assumptions.
  • Results & historyJUnit-authoritative pass/fail, videos, traces, network logs, and heal reports per run.

Download

Get the Windows app

A signed-free NSIS installer with the full IDE, engine, and AI agent. On first launch, QAmate sets up its Python environment and downloads Chromium automatically — no manual pip required.

QAmate for Windows Windows 10 / 11 · 64-bit · NSIS installer (.exe)
Download QAmate Setup

Downloads QAmate-Setup-x.x.x.exe from GitHub Releases. Windows SmartScreen may warn on first run (the build is unsigned) — choose More info → Run anyway.

System requirements

  • Windows 10 or 11 (64-bit)
  • 4 GB RAM minimum (8 GB recommended)
  • ~500 MB free disk (app + Chromium)
  • Internet on first run (downloads Playwright + Chromium)

Prefer to build from source? The developer install via git clone is always available, and you can build the installer yourself — see docs/INSTALLER.md.

Install

Up and running in minutes

Windows is the primary target; the Python engine is cross-platform. Node 18+ and Python 3.11+ required.

clone & install 
# Clone and install dependencies
git clone https://github.com/devesh16145/qamate.git
cd qamate

python -m venv venv
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\playwright install chromium

npm install
run the app 
run_qamate.bat
# or
npx electron .
run demo tests 
venv\Scripts\pytest tests\flows\demo\ -v

On first launch, QAmate copies config.example.json → config.json if missing. See SETUP.md for AI agent configuration and full options.
